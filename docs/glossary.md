# Glossary

| Term                  | Meaning                                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Codename              | "Don't Give Up" (Hungarian: "Ne add fel"). The final name is decided later.                                                                |
| Chapter               | A self-contained part of the story, roughly one in-game period (for example the wood: from the cart crash to the Lark Hill gate).          |
| Phase                 | One stretch of the winter in the story bible timeline, from 0 (the wood) to 5 (thaw). M1 is phase 0; phase 1 starts M2.                    |
| Scene                 | A place and moment in the story; the game shows one background and its characters.                                                         |
| Choice                | A decision the player makes; always changes at least one story variable.                                                                   |
| Story variable        | An ink variable the story reads later (for example warmth, hope, trust). Listed in docs/narrative/story-bible.md.                          |
| Minigame              | A short interactive task started by the story; returns a score band.                                                                       |
| Score band            | The result of a minigame: poor, fair or good. The story branches on it.                                                                    |
| Game mode             | Easy (unlimited minigame retries, gentler timing) or Normal; chosen at a new game, changeable at any time in settings. Ink never reads it. |
| Caretaker and heir    | Miss Agnes (HU Ágnes), the heir and last of the Lark Hill family, hired Mira as Lark Hill's caretaker; the family has forgotten it.        |
| Honesty rules         | The non-negotiable product rules in docs/vision.md.                                                                                        |
| Ink                   | The story scripting language (inkle); files in story/<lang>/.                                                                              |
| Story check           | `npm run check:story`: compiles every language, compares their structure and plays every path.                                             |
| Preview               | The web build of a pull request or of develop, published on GitHub Pages for playtesting.                                                  |
| Owner                 | The product owner (PeterSallai90). Decides scope, look and feel, story beats, naming, release.                                             |
| Full lane / fast lane | The two delivery processes (Lanes in CLAUDE.md).                                                                                           |
