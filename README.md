# Don't Give Up (codename)

A story-first choice game for web and mobile: a mother and her children survive a hard winter
and rebuild a ruined manor. Your choices change the story. No match-3, no pay pressure.

Built with TypeScript, PixiJS and Ink, by an AI agent team led by the product owner.

- Play the latest development build: https://petersallai90.github.io/dont-give-up/
- Vision: [docs/vision.md](docs/vision.md)
- How the team works: [CLAUDE.md](CLAUDE.md)

```
npm ci
npm run dev      # http://localhost:5180
npm run check    # lint, types, languages, story paths, tests
```
